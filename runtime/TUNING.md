## 与附件旧图的主要差异

历史版本 `d85119d` 的 `elevation_mapping_cupy/script/elevation_mapping_cupy/plugins/cvar_layer.py` 对高分表示可通行的 similarity 使用 `mean + k(alpha)*sigma`。因此 alpha 大时分数升高、地图更白。这可解释附件的大 alpha 图更乐观，但与用户提供的上尾**成本** CVaR 公式方向相反。

## EMA 对照的含义

每个格子按**有效投影次数**更新：

```
mean_new = (1-gamma)*mean_old + gamma*q
variance_new = (1-gamma)*variance_old + gamma*(q-mean_new)^2
```

| gamma | 历史权重半衰期（有效观测次数） | 特点 |
| --- | ---: | --- |
| 0.05 | 13.51 | 记忆长、均值平滑；对新视角/新边界响应慢 |
| 0.10 | 6.58 | 中间对照值 |
| 0.20 | 3.11 | 当前基线，响应快 |

gamma 减小不会保证观测方差变小。这里跟踪的是各视角观测波动，不是均值估计误差；不应把 sigma 除以 sqrt(count) 来消除 CVaR 惩罚。gamma 接近 1 还会令更新后残差很小、方差惩罚退化，同时几乎只保留最后一帧。

改变 gamma 需要从相同的有序投影观测重新融合。最终的 mean/variance NPZ 无法反推出另一种 gamma。仅修改 ROS 参数而不重启已构造的融合插件，也不会改变其缓存的增益。

## 最高代价区域较大的原因与拆分

使用同一会话 `ema_sweep_020_030_040/gamma_200/statistics_alpha_095.npz` 的 2527 个已观测世界格，固定 gamma=0.2、分档和投影样本，只比较均值与 CVaR。比例的分母不包含未知格；最深颜色表示 cost=100，不能据此认定为真实障碍面积。

| 统计 | alpha=0.05 | alpha=0.95 |
| --- | ---: | ---: |
| 均值本身已低于 0.20 | 451 格 / 17.85% | 451 格 / 17.85% |
| CVaR 令分数从不低于 0.20 降至低于 0.20 | 17 格 / 0.67% | 488 格 / 19.31% |
| 合计 cost=100 | 468 格 / 18.52% | 939 格 / 37.16% |

sigma 中位数为 0.06191，对应 alpha=0.95 的分数惩罚中位数为 0.12770，而 alpha=0.05 为 0.00672。例如均值 0.30、sigma=0.06 的格子，alpha=0.95 得分约 0.176，进入 100 档；alpha=0.05 得分约 0.293，进入 70 档。高 alpha 地图接近一半的最高代价格，是由原来不属于最高档的格子经 CVaR 惩罚后产生的。

当前 q 已包含 support：在模型原生网格上，score=0.85、support=0.20 时 q=0.17，即使不加 CVaR 也进入最高档。极低 support 的有效观测不是未知格。保存的投影日志只有 q，不能从最终世界格统计中精确分离 score 与 support 各自的贡献；旧模型和当前模型的分数分布也不能直接视为一致。

历史代码还有两个需要区分的行为：

- `d85119d` 的 CVaR 对相似度加标准差，当前实现减标准差。仅作为诊断，在当前同一份统计和当前阈值上换用历史加号，alpha=0.95 的最高档比例会变成 10.92%，而正确减号为 37.16%。这没有重现旧模型或旧图，只隔离了公式方向的影响。原图大 alpha 更白的现象与历史加号方向一致。
